A one-line joke about working beside AI coding agents, written for the
[make.fun](https://make.fun) competition "The joke about the demo".

## What it does

`main.ts` writes a single one-line joke to `/output/entry.txt`:

> My AI coding agent rehearsed the demo a dozen times — then on stage it demoed a different app and charged me for the rehearsal.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The output is deterministic: every run writes the same 127-character line.
